# Git-sandbox

Репозиторій git-sandbox - пісочниця створена для навчання  
Допоможе вам зрозуміти як працювати з гітом

## Що тут лежить

- hero.txt - файлик з інформацією про героя
- notes.txt - журнал героя
- inventory.txt - інвентар героя
- patch.txt - файлик з патчами
- mod-readme.md - тестовий файлик для навчання форматуванню
- world-backup.zip - тестовий файлик для навчання видалення його з гіта, але щоб він остався в теці.
- .gitignore - те без чого всі ваші засекречені файли в теці попадуть в інтернет
- arena.md - файл для тренування праці з гілками, детальніше нижче

## Команди

| Команда           | Навіщо                                                |
|-------------------|-------------------------------------------------------|
| git status        | показує інформацює по гіту                            |
| git diff          | показує відмінності файла від закоміченої версії      |
| git log --oneline | показує всі гіти по одному рядку на кожен             |
| git diff --staged | показує відмінності файла від версії в черзі(git add) |
| git add           | добавля в чергу на коміт                              |
| git commit        | комітить ваші файли                                   |

## Як подивитись історію

Використовуйте git log --oneline покаже всі гіти коротко лише код гіта і назва

```
git log --oneline
```
